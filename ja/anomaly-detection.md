## 異常検知

**Monitoring > Cloud Monitoring > 異常検知** は、Cloud Monitoring が収集した指標パターンを学習し、平常時と異なる異常兆候を自動的に検知します。

しきい値を手動で設定する必要がある通常の通知とは異なり、異常検知は指標の過去のパターンを基準として、**Score** と **Score しきい値** を各時点で自動的に計算します。Score と Score しきい値はいずれも 0〜100 の範囲の値であり、Score が Score しきい値を超えると異常状態と判断します。

異常検知は次の順序で使用します。

1. 異常を検知する指標とリソースを選択して、異常検知項目を作成します。
2. ウィジェットチャートで Score と Score しきい値を確認し、異常発生区間を確認します。
3. 異常検知通知を設定することで、異常発生時に通知を受信できます。

!!! tip "参考"
    作成した異常検知項目は、1 分周期で評価されます。

### 異常検知の作成

**[異常検知の作成]** をクリックすると、異常検知の作成画面に移動します。異常検知のサービスと対象を選択して作成できます。

- **[サービス]**: 異常検知をサポートする NHN Cloud サービスのみ表示され、単一選択のみ可能です。
- **[対象]**: 次の項目の順に設定します。
  - **[種類]**: サービスの指標種類を選択します。
  - **[指標項目]**: 選択した種類に属する指標項目が表示され、複数選択できます。指標項目ごとに選択したリソースの数が合わせて表示されます。
  - **[リソース]**: NHN Cloud 内で作成されたリソースのうち、該当する種類/指標項目に属するリソースが表示され、複数選択できます。

選択した指標項目とリソースの組み合わせごとに異常検知項目が 1 件ずつ作成され、異常検知名は選択した指標項目とリソースを基準として自動生成されます。

すでに作成済みの組み合わせでは追加作成できません。このような場合は **[作成済み]** と表示されます。

**[作成項目のプレビュー]** で、作成される異常検知項目の名前、指標、リソースを表で事前に確認できます。
**[作成]** が完了すると、プレビューに表示された項目がそれぞれ個別の異常検知項目として作成されます。このとき、作成直後に該当項目の通知設定画面へ移動するかどうかを選択できます。

!!! danger "注意"
    作成は全件成功または全件失敗として処理されます。
    選択した項目のうち 1 件でも作成できない項目があると、どの項目も作成されません。

異常検知の作成直後の状態は **[有効化-待機]** であり、異常検知のための学習と推論が完了すると **[有効化-正常]** 状態に変更されます。状態が有効化-正常に変更されるまでは、チャートに Score と Score しきい値が表示されない場合があります。
詳細については、以下の **異常検知の状態** を参照してください。

### 異常検知の一覧

異常検知画面は、左側の一覧エリアと右側のダッシュボードエリアで構成されます。一覧の異常検知項目が右側のダッシュボードにそれぞれ 1 つのウィジェットとして表示されます。

一覧の各項目では、異常検知名、サービス、作成日時、状態情報を確認できます。項目のチェックボックスは、削除など複数の項目を一度に処理する際に使用します。

- フィルター、ソート、検索は左側の一覧と右側のダッシュボードエリアに同時に適用されます。
- **[フィルター]**: サービスと対象のフィルターで、一覧とダッシュボードに表示する項目をフィルタリングできます。フィルターは作成済みの異常検知項目を基準として構成されます。たとえば、Instance サービスの項目のみがある場合、サービスフィルターには Instance のみ表示されます。
- **[ソート]**: 最新順または古い順にソートできます。
- **[検索]**: 異常検知名で検索できます。


### 異常検知ダッシュボード

異常検知ダッシュボードには、作成されたすべての異常検知項目が個別のウィジェットとして自動的に構成されます。

- **[有効化（正常）状態のみ表示]** を選択すると、**[有効化-正常]** 状態の項目のウィジェットのみ表示されます。
- **[ウィジェットデータのダウンロード]** で、ダッシュボードに表示されたウィジェットデータを .csv または .xlsx ファイルとしてダウンロードできます。

!!! tip "参考"
    異常検知ダッシュボードだけでなく、ダッシュボードタブで直接構成したダッシュボードにも異常検知ウィジェットを追加できます。

#### 異常検知ウィジェットチャート

ウィジェットチャートには、次の要素が合わせて表示されます。

- **[指標値]**: 異常検知の対象として選択した指標の実際の収集値です。左側の Y 軸を基準として表示されます。
- **[Score]**: 現在のデータが過去のパターンからどの程度乖離しているかを 0〜100 で換算した数値です。100 に近いほど、平常時のパターンと異なる異常兆候を意味します。右側の Y 軸を基準として表示されます。
- **[Score しきい値]**: Score がしきい値を超えると異常と判断します。Score と同じ右側の Y 軸を基準として表示されます。

Score が Score しきい値を超えた区間が、異常状態と判断された区間です。

#### 異常検知の削除

異常検知の一覧で選択した項目を削除できます。

- 削除した項目と同一の指標項目およびリソースの組み合わせで再作成すると、既存の削除済み項目と連携していたウィジェットおよび通知に自動的に再連携されます。（ただし、データ確保のプロセスが再度実行される場合があります。）

!!! danger "注意"
    異常検知項目を削除しても、その項目を使用するウィジェットや通知は自動的に削除されません。
    削除された項目を使用するウィジェットには異常検知データが表示されず、通知も発生しなくなるため、使用しない場合は手動で整理する必要があります。

#### 異常検知の有効化設定

異常検知の一覧で選択した項目の有効/無効を変更できます。

- **[有効化]**: 異常検知を作成すると、デフォルトで有効化として自動的に設定されます。無効状態から有効化に切り替えた場合、データ確保が再度実行される場合があります。
- **[無効化]**: 該当項目の異常検知が即時停止され、その異常検知で作成したウィジェットに異常検知データが表示されなくなり、通知も発生しなくなります。

#### 異常検知の通知設定

異常検知の一覧で選択した項目の通知を設定できます。

- 選択した項目が設定された状態で、通知作成画面に移動します。通知 1 件につき 1 つのサービスの指標で作成できるため、同一サービスの異常検知項目を選択した場合のみ可能です。


### 異常検知の状態

| 状態 | 説明 | 
| --- | --- |
| 有効化-正常 | - 異常検知が有効化されており、正常に動作中の状態です。 <br> - ウィジェットに異常検知データが表示され、通知が発生します。  |
| 有効化-待機 | - 異常検知が有効化されており、データ確保を進行中の状態です。 <br> - 異常検知の学習と推論に必要なデータを確保するまで、約 6 時間かかる場合があります。データ確保が完了した時点から異常検知データが表示され、通知が発生します。 | 
| 有効化-データ不足 | - 異常検知対象の収集指標データ不足により、異常検知が動作しない状態です。 <br> - サービス障害やリソース削除などにより発生する場合があるため、各サービスのコンソールでリソースの状態を確認してください。 <br>（リソースが削除されている場合は、該当する異常検知設定を削除してください。問題がないにもかかわらずこの状態が続く場合は、カスタマーサポートにお問い合わせください。） | 
| 有効化-一時停止 | - 一時的な問題により、異常検知の動作が一時停止中の状態です。 <br> - システムが自動的に復旧し、復旧完了後に分析のための追加データ確保プロセスが実行される場合があります。 <br>（この状態が長時間続く場合は、カスタマーセンターにお問い合わせください。） |
| 無効化 |  - 異常検知が無効化されており、動作していない状態です。 <br> - 有効化設定により、異常検知を再度動作させることができます。 <br>（ただし、有効化時に追加データ確保のための時間が必要であり、データ確保完了後から異常検知データの表示と通知が発生します。） | 

!!! tip "参考"
    有効化-正常状態を除くすべての状態では、異常検知データが発生せず、通知も発生しません。



## 異常検知の活用

### 異常検知ウィジェット追加

直接作成したダッシュボードにも、異常検知ウィジェットを自由に追加できます。

- ウィジェット追加画面で **[対象種類]** を **[異常検知]** として選択します。
- **[グラフの種類]** は `Anomaly Detection` に固定されます。
- サービスを選択すると、そのサービスで作成された異常検知の一覧が表示されます。目的の異常検知項目が一覧にない場合は、異常検知タブで先に作成する必要があります。
- 選択した異常検知項目ごとに指標設定ブロックが 1 件ずつ追加されます。
- クエリ設定ブロックには、指標値、Score、Score しきい値の 3 つの凡例が自動的に配置されます。異常検知で作成したウィジェットは常にこの 3 種類のデータが合わせて表示されます。（ただし、状態によって表示されない場合があります。）Score と Score しきい値の凡例名と単位、Y 軸の位置は固定値です。
- 集計をサポートする指標では集計設定を使用でき、設定した集計は指標値と Score、Score しきい値のすべてに適用されます。

!!! danger "注意"
    ウィジェットで使用中の異常検知項目が削除された場合、該当ウィジェットの照会と保存は可能ですが、削除された項目のクエリ設定値は変更できません。

#### しきい値の直接指定

異常検知はデータポイントごとにしきい値を自律的に判断するため、基準値が時点によって異なります。固定された基準を使用するには、**[しきい値の直接指定]** を選択して値を入力します。

- しきい値は 0 以上 100 以下の数値のみ入力できます。
- 直接指定すると、データポイントに関わらず入力した値を基準として異常を判断します。
- 選択を解除すると、異常検知が判断したしきい値に従ってチャートに表示されます。

### 異常検知通知

異常が検知されたときに通知を受信するには、異常検知通知を作成します。異常検知通知も既存の指標通知と同様に、通知管理タブ > 通知作成画面で作成できます。

#### しきい値の設定

異常検知はデータポイントごとにしきい値を自律的に判断するため、基準値が時点によって異なります。固定された基準を使用するには、条件ごとに **[直接指定]** を選択して値を入力します。

- しきい値は 0 以上 100 以下の数値のみ入力できます。
- 直接指定すると、データポイントに関わらず入力した値を基準として異常を判断し、通知が発生します。
- 選択を解除すると、異常検知が判断したしきい値を超えた状態が 5 分間継続した場合に通知が発生します。

#### 異常検知通知の確認

- 異常検知通知も既存の指標通知と同様に、通知設定タブ、通知発生履歴タブで確認でき、異常検知通知の場合は別途バッジで区別して表示されます。
- 通知発生履歴では、**[対象種類]** フィルターで異常検知通知のみ照会できます。

!!! danger "注意"
    通知は、異常検知項目が **[有効化-正常]** 状態のときのみ発生します。データ確保中、無効化、データ不足、一時停止状態では通知条件を評価しません。項目の状態は **[異常検知]** 画面で確認できます。
    通知で使用中の異常検知項目が削除された場合、該当通知の照会と保存は可能ですが、削除された項目の通知条件は変更できません。


### 注意事項

- 項目を作成した直後は、異常検知のための学習と推論が完了するまで、Score と Score しきい値が表示されない場合があります。
- 異常検知が使用する元の指標が 30 分間連続して収集されないと、データ不足状態に変更され、Score と Score しきい値も生成されなくなります。指標収集が再開されると、状態は「有効化-待機」または「有効化-正常」に復旧されます。
