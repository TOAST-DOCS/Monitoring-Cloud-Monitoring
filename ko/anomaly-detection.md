## 이상 탐지

**Monitoring > Cloud Monitoring > 이상 탐지**는 Cloud Monitoring이 수집한 지표 패턴을 학습하여 평소와 다른 이상 징후를 자동으로 감지합니다.

임계치를 직접 정해야 하는 일반 알림과 달리, 이상 탐지는 지표의 과거 패턴을 기준으로 **Score**와 **Score 임계치**를 매 시점 자동으로 계산합니다. Score와 Score 임계치는 모두 0~100 범위의 값이며, Score가 Score 임계치를 넘어서면 이상 상태로 판단합니다.

이상 탐지는 다음 순서로 사용합니다.

1. 이상 탐지할 지표와 리소스를 선택하여 이상 탐지 항목을 생성합니다.
2. 위젯 차트에서 Score와 Score 임계치를 확인하여 이상 발생 구간을 확인합니다.
3. 이상 탐지 알림을 설정하여 이상 발생 시 알림을 수신할 수 있습니다.

!!! tip "알아두기"
    생성한 이상 탐지 항목은 1분 주기로 평가됩니다.

### 이상 탐지 생성

**이상 탐지 생성**을 클릭하면 이상 탐지 생성 화면으로 이동합니다. 이상 탐지 서비스와 대상을 선택하여 생성할 수 있습니다.

- **서비스**: 이상 탐지를 지원하는 NHN Cloud 서비스만 표시되며, 단일 선택만 가능합니다.
- **대상**: 아래 항목 순서대로 설정합니다.
  - **유형**: 서비스의 지표 유형을 선택합니다.
  - **지표 항목**: 선택한 유형에 속한 지표 항목이 표시되며, 여러 개 선택할 수 있습니다. 지표 항목마다 선택한 리소스 개수가 함께 표시됩니다.
  - **리소스**: NHN Cloud 내 생성된 리소스 중 해당 유형/지표 항목에 속한 리소스가 표시되며, 여러 개 선택할 수 있습니다.

선택한 지표 항목과 리소스의 조합마다 이상 탐지 항목이 1개씩 생성되며, 이상 탐지 이름은 선택한 지표 항목과 리소스를 기준으로 자동 생성됩니다.

이미 생성된 조합으로는 추가 생성할 수 없습니다. 이러한 경우는 **이미 생성됨**으로 표시됩니다.

**생성 항목 미리보기**로 생성될 이상 탐지 항목의 이름, 지표, 리소스를 표로 미리 확인할 수 있습니다.
**생성**이 완료되면 미리보기에 표시된 항목이 각각 개별 이상 탐지 항목으로 생성됩니다. 이때, 생성 직후 해당 항목들로 바로 알림 설정 화면으로 이동할지 선택할 수 있습니다.

!!! danger "주의"
    생성은 전체 성공 또는 전체 실패로 처리됩니다.
    선택한 항목 중 하나라도 생성할 수 없는 항목이 있으면 어떤 항목도 생성되지 않습니다.

이상 탐지 생성 직후 상태는 **활성화-대기**이며, 이상 탐지를 위한 학습 및 추론이 완료되면 **활성화-정상** 상태로 변경됩니다. 상태가 활성화-정상으로 변경되기 전까지는 차트에 Score와 Score 임계치가 표시되지 않을 수 있습니다.
자세한 내용은 아래 **이상 탐지 상태**를 참고하세요.

### 이상 탐지 목록

이상 탐지 화면은 좌측 목록 영역과 우측 대시보드 영역으로 구성됩니다. 목록의 이상 탐지 항목이 우측 대시보드에 각각 하나의 위젯으로 표시됩니다.

목록의 각 항목에서는 이상 탐지 이름, 서비스, 생성 일시, 상태 정보를 확인할 수 있습니다. 항목의 체크 박스는 삭제와 같이 여러 항목을 한 번에 처리할 때 사용합니다.

- 필터, 정렬, 검색은 좌측 목록과 우측 대시보드 영역에 동시 적용됩니다.
- **필터**: 서비스와 대상 필터로 목록과 대시보드에 표시할 항목을 필터링할 수 있습니다. 필터는 생성된 이상 탐지 항목을 기준으로 구성됩니다. 예를 들어 Instance 서비스의 항목만 있으면 서비스 필터에는 Instance만 표시됩니다.
- **정렬**: 최신순 또는 오래된 순으로 정렬할 수 있습니다.
- **검색**: 이상 탐지 이름으로 검색할 수 있습니다.


### 이상 탐지 대시보드

이상 탐지 대시보드에는 생성된 모든 이상 탐지 항목이 개별 위젯으로 자동 구성됩니다.

- **활성화(정상) 상태만 보기**를 선택하면 **활성화-정상** 상태인 항목의 위젯만 표시됩니다.
- **위젯 데이터 다운로드**에서 대시보드에 표시된 위젯 데이터를 .csv 또는 .xlsx 파일로 내려받을 수 있습니다.

!!! tip "알아두기"
    이상 탐지 대시보드뿐만 아니라 대시보드 탭의 직접 구성한 대시보드에도 이상 탐지 위젯을 추가할 수 있습니다.

#### 이상 탐지 위젯 차트

위젯 차트에는 다음 요소가 함께 표시됩니다.

- **지표 값**: 이상 탐지 대상으로 선택한 지표의 실제 수집 값입니다. 좌측 Y축 기준으로 표시됩니다.
- **Score**: 현재 데이터가 과거 패턴에서 벗어난 정도를 0~100으로 환산한 수치입니다. 100에 가까울수록 평소 패턴과 다른 이상 징후를 의미합니다. 우측 Y축 기준으로 표시됩니다.
- **Score 임계치**: Score가 임계치를 넘으면 이상으로 판단합니다. Score와 같은 우측 Y축 기준으로 표시됩니다.

Score가 Score 임계치를 넘어선 구간이 이상 상태로 판단된 구간입니다.

#### 이상 탐지 삭제

이상 탐지 목록에서 선택한 항목을 삭제할 수 있습니다.

- 삭제한 항목과 동일한 지표 항목 및 리소스 조합으로 다시 생성하면, 기존에 삭제된 항목과 연동되었던 위젯 및 알림에 자동으로 다시 연동됩니다. (단, 데이터 확보 과정이 다시 진행될 수 있습니다.)

!!! danger "주의"
    이상 탐지 항목을 삭제해도 해당 항목을 사용하는 위젯이나 알림은 자동으로 삭제되지 않습니다.
    삭제된 항목을 사용하는 위젯에는 이상 탐지 데이터가 표시되지 않으며 알림도 더 이상 발생하지 않으므로, 사용하지 않는 경우 직접 정리해야 합니다.

#### 이상 탐지 활성화 설정

이상 탐지 목록에서 선택한 항목의 활성화 여부를 변경할 수 있습니다.

- **활성화**: 이상 탐지를 생성하면 기본적으로 활성화로 자동 설정됩니다. 비활성화 상태에서 활성화로 전환하는 경우 데이터 확보가 다시 진행될 수 있습니다.
- **비활성화**: 해당 항목의 이상 탐지가 즉시 중단되며, 해당 이상 탐지로 생성한 위젯에 이상 탐지 데이터가 표시되지 않으며 알림도 더 이상 발생하지 않습니다.

#### 이상 탐지 알림 설정

이상 탐지 목록에서 선택한 항목의 알림을 설정할 수 있습니다.

- 선택한 항목이 설정된 상태로 알림 생성 화면으로 이동합니다. 알림 1개당 하나의 서비스 지표들로 생성할 수 있으므로, 동일 서비스의 이상 탐지 항목을 선택한 경우에만 가능합니다.


### 이상 탐지 상태

| 상태 | 설명 | 
| --- | --- |
| 활성화-정상 | - 이상 탐지가 활성화되어 정상적으로 동작 중인 상태입니다. <br> - 위젯에 이상 탐지 데이터가 표시되며 알림이 발생합니다.  |
| 활성화-대기 | - 이상 탐지가 활성화되어 데이터 확보를 진행 중인 상태입니다. <br> - 이상 탐지 학습 및 추론에 필요한 데이터를 확보하기까지 약 6시간이 소요될 수 있습니다. 데이터 확보가 완료된 시점부터 이상 탐지 데이터가 표시되며 알림이 발생합니다. | 
| 활성화-데이터 부족 | - 이상 탐지 대상의 수집 지표 데이터 부족으로 이상 탐지가 동작하지 않는 상태입니다. <br> - 서비스 장애나 리소스 삭제 등으로 발생할 수 있으니, 각 서비스 콘솔에서 리소스 상태를 확인하세요. <br>(리소스가 삭제되었다면 해당 이상 탐지 설정을 삭제하세요. 문제가 없는데도 해당 상태가 지속되면 고객지원에 문의하세요.) | 
| 활성화-일시 중단 | - 일시적인 문제로 인해 이상 탐지 동작이 잠시 중단된 상태입니다. <br> - 시스템이 자동으로 복구하며, 복구 완료 후 분석을 위한 추가 데이터 확보 과정이 진행될 수 있습니다. <br> (해당 상태가 장시간 지속될 경우 고객센터로 문의하세요.) |
| 비활성화 |  - 이상 탐지가 비활성화되어 동작하지 않는 상태입니다. <br> - 활성화 설정으로 이상 탐지를 다시 동작시킬 수 있습니다. <br>(단, 활성화 시 추가 데이터 확보를 위한 시간이 소요되며, 데이터 확보 완료 이후부터 이상 탐지 데이터 표시 및 알림이 발생합니다.) | 

!!! tip "알아두기"
    활성화-정상 상태를 제외한 모든 상태는 이상 탐지 데이터가 발생되지 않으며 이에 따라 알림도 발생하지 않습니다.



## 이상 탐지 활용

### 이상 탐지 위젯 추가

직접 생성한 대시보드에도 이상 탐지 위젯을 자유롭게 추가할 수 있습니다.

- 위젯 추가 화면에서 **대상 유형**을 **이상 탐지**로 선택합니다.
- **그래프 유형**은 `Anomaly Detection`으로 고정됩니다.
- 서비스 선택 시, 해당 서비스로 생성된 이상 탐지 목록이 표시됩니다. 원하는 이상 탐지 항목이 목록에 없는 경우, 이상 탐지 탭에서 먼저 생성해야 합니다.
- 선택한 이상 탐지 항목마다 지표 설정 블록이 1개씩 추가됩니다.
- 쿼리 설정 블록에는 지표 값, Score, Score 임계치 세 개의 범례가 자동으로 배치됩니다. 이상 탐지로 생성한 위젯은 항상 이 3가지 데이터가 함께 표시됩니다. (단, 상태에 따라 표시되지 않을 수 있음) Score와 Score 임계치의 범례명과 단위, Y축 위치는 고정값입니다.
- 집계를 지원하는 지표에서는 집계 설정을 사용할 수 있으며, 설정한 집계는 지표 값과 Score, Score 임계치에 모두 적용됩니다.

!!! danger "주의"
    위젯에서 사용 중인 이상 탐지 항목이 삭제된 경우, 해당 위젯의 조회와 저장은 가능하지만 삭제된 항목의 쿼리 설정값은 변경할 수 없습니다.

#### 임계치 직접 지정

이상 탐지는 데이터 포인트마다 임계치를 스스로 판단하므로 기준 값이 시점에 따라 달라집니다. 고정된 기준을 사용하려면 **임계치 직접 지정**을 선택하고 값을 입력합니다.

- 임계치는 0 이상 100 이하의 숫자만 입력할 수 있습니다.
- 직접 지정하면 데이터 포인트에 관계없이 입력한 값을 기준으로 이상을 판단합니다.
- 선택을 해제하면 이상 탐지가 판단한 임계치에 따라 차트에 표시됩니다.

### 이상 탐지 알림

이상이 탐지되었을 때 알림을 수신하려면 이상 탐지 알림을 생성합니다. 이상 탐지 알림도 기존 지표 알림과 같이 알림 관리 탭 > 알림 생성 화면에서 생성할 수 있습니다.

#### 임계치 설정

이상 탐지는 데이터 포인트마다 임계치를 스스로 판단하므로 기준 값이 시점에 따라 달라집니다. 고정된 기준을 사용하려면 조건별로 **직접 지정**을 선택하고 값을 입력합니다.

- 임계치는 0 이상 100 이하의 숫자만 입력할 수 있습니다.
- 직접 지정하면 데이터 포인트에 관계없이 입력한 값을 기준으로 이상을 판단하여 알림이 발생합니다.
- 선택을 해제하면 이상 탐지가 판단한 임계치 초과 상태가 5분 지속된 경우 알림이 발생합니다.

#### 이상 탐지 알림 확인

- 이상 탐지 알림도 기존 지표 알림과 같이 알림 설정 탭, 알림 발생 이력 탭에서 확인할 수 있으며, 이상 탐지 알림의 경우에는 별도 배지로 구분할 수 있게 표시합니다.
- 알림 발생 이력에서는 **대상 유형** 필터로 이상 탐지 알림만 조회할 수 있습니다.

!!! danger "주의"
    알림은 이상 탐지 항목이 **활성화-정상** 상태일 때만 발생합니다. 데이터 확보 중이거나 비활성화, 데이터 부족, 일시 중단 상태에서는 알림 조건을 평가하지 않습니다. 항목의 상태는 **이상 탐지** 화면에서 확인할 수 있습니다.
    알림에서 사용 중인 이상 탐지 항목이 삭제된 경우, 해당 알림은 조회와 저장은 가능하지만 삭제된 항목의 알림 조건은 변경할 수 없습니다.


### 유의 사항

- 항목을 생성한 직후에는 이상 탐지를 위한 학습 및 추론이 완료될 때까지 Score와 Score 임계치가 표시되지 않을 수 있습니다.
- 이상 탐지가 사용하는 원본 지표가 연속 30분 동안 수집되지 않으면 데이터 부족 상태로 변경되고, Score와 Score 임계치도 더 이상 생성되지 않습니다. 지표 수집이 다시 시작되면 상태는 '활성화-대기' 또는 '활성화-정상'으로 복구됩니다.
