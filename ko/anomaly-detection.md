## 이상 탐지

**Monitoring > Cloud Monitoring > 이상 탐지**에서는 NHN Cloud 리소스에서 수집한 지표의 평소 패턴을 AI가 학습해, 평소와 다른 흐름이 나타나면 이를 감지할 수 있습니다.

임계치를 직접 정해야 하는 일반 알림과 달리, 이상 탐지는 지표의 과거 패턴을 기준으로 **Score**와 **Score 임계치**를 매 시점 자동으로 계산합니다. Score와 Score 임계치는 모두 0~100 범위의 값이며, Score가 Score 임계치를 넘어서면 이상 상태로 판단합니다.

이상 탐지는 다음 순서로 사용합니다.

1. **이상 탐지 생성**으로 감시할 지표와 리소스를 선택해 이상 탐지 항목을 생성합니다.
2. 생성한 항목의 지표값과 Score를 **이상 탐지** 화면의 차트에서 확인합니다.
3. 이상 상태를 알림으로 받으려면 이상 탐지 알림을 생성합니다.

> [참고]
> 생성한 이상 탐지 항목은 1분 주기로 평가됩니다.

### 이상 탐지 목록

이상 탐지 화면은 왼쪽의 **이상 탐지 목록**과 오른쪽의 차트 영역으로 구성됩니다. 목록의 이상 탐지 항목이 오른쪽에 각각 하나의 차트로 표시됩니다.

목록의 각 항목에서는 이상 탐지 이름, 서비스, 생성 일시와 현재 상태를 확인할 수 있습니다. 항목의 체크박스는 삭제와 같이 여러 항목을 한 번에 처리할 때 사용합니다.

- **이상 탐지 검색**에 이름을 입력해 목록을 검색할 수 있습니다.
- 목록은 생성 일시를 기준으로 **최신순** 또는 **오래된순**으로 정렬할 수 있습니다.
- 화면 상단의 **서비스**, **대상** 필터로 표시할 항목을 좁힐 수 있습니다.
- **활성화(정상) 상태만 보기**를 선택하면 현재 이상 탐지가 실제로 동작하고 있는 항목만 표시됩니다.

차트 영역 상단에서는 조회 기간을 선택할 수 있으며, 이전/다음 버튼으로 조회 구간을 이동할 수 있습니다. **위젯 데이터 다운로드**로 차트에 표시된 데이터를 내려받을 수 있습니다.

#### 이상 탐지 차트

이상 탐지 항목마다 하나의 차트가 표시되며, 차트 제목은 이상 탐지 이름과 현재 상태로 구성됩니다. 하나의 차트에는 다음 세 가지 계열이 함께 표시됩니다.

- **지표값**: 이상 탐지 대상으로 선택한 지표의 실제 수집 값입니다. 왼쪽 Y축에 지표의 단위로 표시됩니다.
- **Score**: AI가 계산한 0~100 범위의 점수입니다. 값이 클수록 평소 패턴에서 벗어난 상태를 의미합니다. 오른쪽 Y축에 표시됩니다.
- **Score 임계치**: 이상 여부를 판단하는 기준선입니다. Score와 같은 오른쪽 Y축에 표시됩니다.

Score가 Score 임계치를 넘어선 구간이 이상 상태로 판단된 구간입니다.

#### 상태

이상 탐지 항목은 세 가지 상태 값을 가지며, 세 가지가 모두 정상일 때만 이상 탐지가 동작합니다. **활성화(정상) 상태만 보기**는 이 조건을 모두 만족하는 항목만 표시합니다.

| 상태        | 값       | 설명                                                                                                          |
| ----------- | -------- | ------------------------------------------------------------------------------------------------------------- |
| 활성화 여부 | 활성화   | 이상 탐지를 수행합니다.                                                                                       |
|             | 비활성화 | 이상 탐지를 일시 중지합니다. Score와 Score 임계치가 더 이상 생성되지 않습니다.                                |
| 모델 상태   | 대기     | 모델이 아직 준비되지 않았습니다. 항목을 생성했거나 비활성화한 항목을 다시 활성화한 직후의 상태입니다.         |
|             | 정상     | 모델이 정상적으로 동작하고 있습니다.                                                                          |
|             | 오류     | 모델에 오류가 발생했습니다.                                                                                   |
| 지표 상태   | 존재     | 이상 탐지가 사용하는 원본 지표가 수집되고 있습니다.                                                           |
|             | 미존재   | 원본 지표가 30분 동안 수집되지 않았습니다. 리소스가 삭제되었거나 해당 서비스의 지표 수집이 중단된 경우입니다. |

> [참고]
> 지표 상태가 **미존재**이거나 모델 상태가 **오류**인 항목은 Score가 생성되지 않습니다.
> 해당 항목을 사용하는 알림도 발생하지 않습니다.

### 이상 탐지 생성

**+ 이상 탐지 생성**을 클릭하면 이상 탐지 생성 화면이 열립니다. 서비스와 대상은 필수 값이므로 반드시 선택해야 합니다.

- **서비스**: 이상 탐지를 지원하는 NHN Cloud 서비스만 표시되며, 단일 선택만 가능합니다.
- **대상**: **유형**, **지표 항목**, **리소스**를 차례로 선택합니다.
  - **유형**: 선택한 서비스에서 이상 탐지를 지원하는 지표의 유형이 표시됩니다.
  - **지표 항목**: 선택한 유형에 속한 지표 항목이 표시되며, 복수 개 선택할 수 있습니다. 지표 항목마다 선택한 리소스 개수가 함께 표시됩니다.
  - **리소스**: 선택한 지표 항목을 **현재 보고하고 있는** 리소스만 후보로 표시되며, 복수 개 선택할 수 있습니다.

선택한 지표 항목과 리소스의 조합마다 이상 탐지 항목이 1개씩 생성됩니다.

이상 탐지 이름은 선택한 지표 항목과 리소스로 자동 생성되며, 직접 입력하지 않습니다.

이미 생성된 조합은 **이미 생성됨**으로 표시되어 선택할 수 없습니다.

**생성 항목 미리보기**를 클릭하면 실제로 생성될 이상 탐지 항목의 이름, 지표, 리소스를 표로 미리 확인할 수 있습니다. **생성**을 클릭하면 목록에 표시된 항목이 각각 개별 이상 탐지 항목으로 생성됩니다.

> [주의]
> 생성은 전체 성공 또는 전체 실패로 처리됩니다.
> 선택한 항목 중 하나라도 생성할 수 없는 항목이 있으면 어떤 항목도 생성되지 않습니다.

생성 직후에는 모델 상태가 **대기**이며, AI 모델이 지표 패턴 학습을 마치면 **정상**으로 변경됩니다. 모델 준비가 완료될 때까지는 차트에 Score와 Score 임계치가 표시되지 않을 수 있습니다.

### 이상 탐지 활성화/비활성화 및 삭제

이상 탐지 목록에서 항목을 선택한 뒤 활성화 여부를 변경하거나 삭제할 수 있습니다. 여러 항목을 선택해 한 번에 처리할 수도 있습니다.

- **비활성화**하면 해당 항목의 이상 탐지가 중지되고, Score와 Score 임계치가 더 이상 생성되지 않습니다.
- 다시 **활성화**하면 모델 상태가 **대기**로 초기화된 뒤 모델이 재준비됩니다.
- **삭제**하면 확인 모달이 열립니다. 삭제한 항목은 목록에 표시되지 않으며, 이상 탐지도 중지됩니다.

삭제한 항목과 같은 지표 항목·리소스 조합으로 다시 생성할 수 있습니다. 이 경우 새로 생성한 항목으로 취급되어 모델 상태가 **대기**부터 다시 시작됩니다.

> [주의]
> 이상 탐지 항목을 삭제해도 해당 항목을 사용하는 알림은 자동으로 삭제되지 않습니다.
> 삭제된 항목을 사용하는 알림은 더 이상 발생하지 않으므로, 사용하지 않는 알림은 직접 정리해야 합니다.

### 이상 탐지 알림

이상 상태가 감지되었을 때 알림을 받으려면 이상 탐지 알림을 생성합니다. 생성한 이상 탐지 알림은 **알림 관리**의 알림 목록에 지표 알림과 함께 표시되며, 목록에서 각 알림의 대상 유형(지표/이상 탐지)을 확인할 수 있습니다.

#### 이상 탐지 알림 생성/수정

알림 생성 화면의 기본 정보에서 **대상 유형**을 **이상 탐지**로 선택합니다. 이름, 대상 유형, 서비스, 알림 설정, 알림 수신 대상은 필수 값이므로 반드시 입력해야 합니다.

- **이름**: 최대 40자까지 입력할 수 있습니다.
- **설명**: 최대 100자까지 입력할 수 있습니다.
- **서비스**: 단일 선택만 가능합니다. 알림에 포함되는 이상 탐지 항목은 모두 같은 서비스에 속해야 합니다.

알림 설정에서 **유형**, **지표 항목**, **리소스**를 선택합니다. 지표 항목과 리소스는 복수 개 선택할 수 있으며, **전체 선택**으로 리소스를 모두 선택할 수도 있습니다.

지표 항목과 리소스를 선택하면 조합마다 설정 블록이 추가되고, 블록 안에 쿼리 설정 블록이 기본 1개 포함됩니다. 각 쿼리는 알파벳 순서(A, B, C, ...)로 자동 번호가 부여되며, 복사·삭제·접기가 가능합니다. 이상 탐지 알림의 쿼리 설정 블록에서는 집계와 조건을 설정합니다.

집계를 지원하는 지표에서는 **집계** 설정 영역이 표시됩니다. **사용**을 선택하면 집계 항목(평균, 최소, 최대)을 선택할 수 있으며, **사용 안 함**(기본값)을 선택하면 원본 데이터를 기반으로 알림을 판단합니다.

**조건**은 **+ 추가**로 1개 이상 입력해야 합니다. 조건 표에서는 조건 설정 방식, 비교 방법, 임계치(Score), 지속 시간을 확인하고 수정할 수 있습니다.

- **직접 지정을 선택하지 않은 경우**(기본값): AI가 계산한 **이상 탐지 임계치**를 기준으로 판단합니다. Score가 이상 탐지 임계치 이상(`>=`)인 상태가 **5분** 동안 지속되면 알림이 발생합니다. 비교 방법, 임계치, 지속 시간은 변경할 수 없습니다.
- **직접 지정을 선택한 경우**: 비교 방법, 임계치, 지속 시간을 직접 지정합니다.
  - **비교 방법**: `>=`, `>`, `<=`, `<`, `=`, `!=` 중에서 선택합니다.
  - **임계치(Score)**: Score와 비교할 값으로, 0~100 사이의 값을 입력합니다. 소수점 입력이 가능합니다.
  - **지속 시간**: 조건을 만족하는 상태가 지정한 시간 동안 지속되면 알림이 발생합니다. 분 단위로 입력하며, `0분`을 입력하면 조건을 만족하는 즉시 알림이 발생합니다.

알림 수신 대상은 1개 이상 선택해야 합니다. 설정 방법은 일반 알림과 동일합니다. 자세한 내용은 **알림 설정**의 알림 생성/수정을 참고합니다.

> [주의]
> 알림에서 사용 중인 이상 탐지 항목이 삭제된 경우, 해당 알림은 조회와 저장은 가능하지만 삭제된 항목의 알림 조건은 변경할 수 없습니다.
> 조건을 변경하려면 삭제된 항목을 알림에서 먼저 제외해야 합니다.

#### 이상 탐지 알림 발생 이력

이상 탐지 알림의 발생 이력은 **알림 발생 이력** 탭에서 지표 알림과 함께 확인할 수 있습니다. 검색 필터의 대상 유형을 **전체**(기본값), **지표**, **이상 탐지** 중에서 선택해 조회 범위를 좁힐 수 있습니다.

이상 탐지 알림은 결과 값으로 **Score**가 표시되며, 알림 발생 이력 보기에서는 임계치로 알림 발생 시점의 **이상 탐지 임계치** 또는 직접 지정한 임계치가 표시됩니다.

### 유의 사항

- 이상 탐지 항목은 1분 주기로 평가됩니다.
- 항목을 생성한 직후에는 모델 준비가 완료될 때까지 Score와 Score 임계치가 표시되지 않을 수 있습니다.
- 이상 탐지가 사용하는 원본 지표가 30분 동안 수집되지 않으면 지표 상태가 **미존재**로 변경되고, Score와 Score 임계치도 더 이상 생성되지 않습니다. 지표 수집이 다시 시작되면 상태는 자동으로 **존재**로 복구됩니다.
- 지표 관리에서 해당 서비스의 지표 수집을 중단하면 원본 지표가 더 이상 수집되지 않으므로 이상 탐지도 함께 중단됩니다.
- 삭제한 이상 탐지 항목의 Score와 Score 임계치는 더 이상 조회할 수 없습니다.
